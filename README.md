# Magazin Frontend

Telefon va kompyuterga moslashadigan oziq-ovqat magazini boshqaruv paneli.

## Ishga tushirish
1. Node.js 20+ o‘rnating.
2. `.env.example` faylini `.env.local` nomiga nusxalang.
3. `NEXT_PUBLIC_API_URL` qiymatini backend manziliga sozlang.
4. `npm install`
5. `npm run build`
6. `npm start`

## Hozirgi ekranlar
- Login (JWT)\n- POS savdo oynasi va savdo tarixi\n- Savdoda ombor qoldig‘ini tekshirish, tannarxni saqlash va nasiya savdoda qarz yaratish
- Dashboard ko‘rsatkichlari
- Mahsulotlar va ombor qoldig‘i
- Xarajatlar
- Qarzlar

Bu MVP bosqichi. POS savdo oynasi, chek printeri, fiskal kassa va to‘liq foyda-zarar hisoboti keyingi ishlab chiqish bosqichlarida qo‘shiladi.
